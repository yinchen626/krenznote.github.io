主题地图（MOC）

这张图不是原心智图的复制，而是按「实战作画时会怎么思考」重新组织的知识骨架。

一、先看整体：画面要回答的三个问题

  1. 我要观众先看哪里？ → 01_焦点与视觉引导
  2. 光从哪里来、环境是什么？ → 02_光影系统 + 08_环境与空气透视
  3. 整体调子是否和谐？ → 11_画面黑白灰关系 + 12_阶层调子控制

二、造型阶段：先把形和阶搞定

  • 04_正负形与图形构成：用黑白/正负形检查剪影是否清晰。
  • 05_塑造与信息量：用 5~7 阶调子塑造体积，同时控制信息密度。
  • 06_色彩三属性：在明度关系稳定后，再替换色相/纯度。

三、上色阶段：先素描关系，后色彩

固有色 → 环境光 → 直射光 → 反光/补光 → 藏色/微调

对应笔记： - 03_固有色与环境色 - 02_光影系统 - 07_色调与氛围

四、进阶：让画面有「氛围」和「光感」

  • 08_环境与空气透视：用大气透视推开空间。
  • 09_滤镜与光效：用柔化、光柱、空气粒子制造情绪。
  • 12_阶层调子控制：把调子当成社会阶层，主动压缩/拉开阶级差。

五、参考与收尾

  • 10_参考图的信息提取：不要照抄参考，要提取「曝光、色温、明暗交界线、调子阶层」。
  • 13_实用技巧与误区：常见坑和训练方法。
  • 91_L1-L8_课程索引：如果忘了某个知识点来自哪节课，查这张表。

六、核心链路（一条可执行的作画流程）

1. 确定焦点 → 01_焦点与视觉引导
2. 建立光影系统（主光/环境/反光） → 02_光影系统
3. 用正负形切出剪影 → 04_正负形与图形构成
4. 分出 5~7 阶调子 → 05_塑造与信息量
5. 在保持明度关系下上固有色/环境色 → 03_固有色与环境色
6. 加入直射光/高光/闭塞 → 02_光影系统
7. 用藏色、滤镜、大气透视提升氛围 → 07_色调与氛围 / 09_滤镜与光效
8. 回头检查黑白灰大关系与阶层 → 11_画面黑白灰关系 / 12_阶层调子控制
